# Кредитный кабинет — фронтенд

Код по макету «Кредитный кабинет — макет» (Claude Design): 72 экрана и состояния, React 18 + TypeScript + Vite, роутинг на react-router.

## Запуск

```bash
npm install
npm run dev
```

- `http://localhost:5173/` — экран входа (A1), с него начинаются все сценарии.
- `http://localhost:5173/screens` — карта всех экранов по разделам макета.
- `npm run build` — проверка типов и сборка в `dist/`.

## Структура

| Путь | Что там |
| --- | --- |
| `src/ui/` | Дизайн-система: `index.tsx` (компоненты), `tokens.css`, `bundle.css` — копия из `../Дизайн-система` |
| `src/styles/screens.css` | Стили экранов (классы `kn-*`) из макета |
| `src/screens/*.tsx` | По одному компоненту на артборд, имя файла = имя артборда (`B3-Offers.tsx` ↔ `B3-Offers.dc.html`) |
| `src/screens/registry.ts` | Список экранов, адресов и разделов — из `canvas.json` |
| `src/lib/` | `useMergeState` (состояние экрана), `parseStyle` |
| `design-source/` | Исходники макета (`.dc.html`, `canvas.json`), из которых сгенерирован код |
| `scripts/convert-design.mjs` | Конвертер макета в код |

Адрес экрана — имя артборда в нижнем регистре: `B9a-Approved` → `/b9a-approved`, `Main` → `/`.
Мобильные экраны (`/m-*`) нарисованы на 390 px и на широком экране показываются по центру.

## Как устроен экран

Каждый экран — функция-компонент и хук `useScreen()` рядом с ним. Хук содержит демо-данные и логику макета
(переключатели, калькулятор, ввод кода) и отдаёт объект `v`, который читает разметка. Общие части — `NavClient`,
`HeaderClient`, `NavBank`, `MobileTop`, `AssistantPanel`, `DecisionPanel` и др. — обычные компоненты с пропсами.

Данные сейчас синтетические и лежат прямо в хуках. Подключая API, заменяйте содержимое `useScreen()` на запросы,
разметку трогать не нужно.

## Если макет изменился

1. Обновите файлы в `design-source/` (выгрузка проекта из Claude Design).
2. `npm run import-design` — перегенерирует `src/screens/`.

Команда перезаписывает `src/screens/` целиком. Когда начнёте править экраны руками, перестаньте её запускать
или переносите изменения макета вручную.
