# docs

Владельцы: Евгений (API и модель данных), Интеграции (`integrations.md`).

| Файл | Что внутри |
| --- | --- |
| `openapi.json` | сгенерированный контракт API, источник типов для фронта |
| `data-model.md` | ER-диаграмма и описание таблиц |
| `state-machine.md` | статусы, переходы и роли |
| `manual-testing.md` | ручной прогон ядра: вход, заявки, консоль, негативные кейсы, аудит |

Контракт API фиксируется во вторник вечером. После этого изменения эндпоинтов
сначала анонсируются фронту, потом попадают в код и `openapi.json`.
