# Коллекция Bruno

Демо-сценарии для API банка: вход, заявка клиента, консоль банка, режим жюри, сбои источников, ассистент.

## Как открыть
1. Установите [Bruno](https://www.usebruno.com).
2. Collection -> Open Collection -> папка `docs/collection`.
3. Справа сверху выберите окружение `local` (api: http://localhost:8000, mocks: http://localhost:8090).
4. Поднимите стек: `docker compose up`.

## Порядок запуска
Папки идут по номерам, запросы внутри - по порядку. Токены и номера заявок хранятся в переменных, поэтому сначала запускайте `01 Вход`.

1. `01 Вход` - токены всех пользователей (пароль `demo123`).
2. `02 Заявка клиента` - Игорь создаёт и отправляет заявку.
3. `03 Консоль банка` - Ольга берёт заявку и принимает решение. Если заявка ещё не в ручной проверке, вернётся 409 - это нормально.
4. `04 Режим жюри` - сбой БКИ, скорость, сброс.
5. `05 Сбои источников` - выключаем БКИ в моках, отправляем заявку Анны, ждём manual_review. В конце сброс источников.
6. `06 Ассистент` - три вопроса.

Из консоли (в папке `docs/collection`): `npx @usebruno/cli@1 run . -r --env local`.
