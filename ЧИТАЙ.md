# Хакатон Альфа-Банка — «Умный кредитный кабинет предпринимателя»

## Концепция/
Продуктовая концепция: задача и критерии жюри, персоны, боли, CJM, ИИ-ассистент, логика подбора, метрики, MVP, архитектура, сценарий демо, риски.
- `.pdf` — для чтения и печати, `.docx` — для правок.
- Живая версия с комментариями: https://claude.ai/code/artifact/aa0e4cef-41b8-4787-91ae-35befc82a4fe

## Дизайн-система/
- `preview/index.html` — открыть в браузере: все компоненты, переключатель светлой и тёмной темы, пример экрана. Нужен интернет только для шрифта Golos Text.
- `README.md` — правила: тон, числа и деньги, цвет, типографика, сетка, ассистент в интерфейсе, доступность.
- `tokens.json` — токены (источник правды), `tokens.css` — те же токены как CSS-переменные.
- `components/src/index.tsx` — исходник компонентов для React + TypeScript (импортирует только `react`).
- `components/bundle.css` — стили компонентов (классы `kk-*`), подключать после `tokens.css`.
- `components/bundle.js` — готовая сборка: `window.Cabinet`, нужен React 18 на странице (`components/lib/`).
- `components/index.d.ts` — типы пропсов; `components/<Компонент>/README.md` — когда и как использовать.
- `assets/Icons/` — 20 иконок SVG, `assets/Brand/assistant-mark.svg` — знак ассистента.
- `screenshots/` — все компоненты в светлой и тёмной теме (PNG, для слайдов).
- Живая версия: артефакт «Кредитный кабинет» (Design System) в Claude.

### Подключение в React-проект
1. Скопировать `tokens.css`, `components/bundle.css` и `components/src/index.tsx` (например, в `src/ui/`).
2. Импортировать стили: `import './ui/tokens.css'; import './ui/bundle.css';`
3. Использовать: `import { ProductCard, PaymentLoadMeter, formatMoney } from './ui';`
4. Тёмная тема — атрибут `data-theme="dark"` на `<html>`.

## frontend/
Фронтенд кабинета клиента и консоли банка: React 19 + TypeScript + Vite, дизайн-система в `src/shared/ui`, страницы собраны из компонентов. Пока работает на мок-бэкенде. Запуск: `cd frontend && npm install && npm run dev`, подробности — `frontend/README.md`.

## app/
Прототип, сгенерированный из макета (72 артборда). Используется как эталон при переносе экранов во `frontend/`; после переноса папку можно удалить.
