# DocumentUpload

Зона загрузки документов и список файлов со статусом проверки.

**Что передать:** `onFiles` (получает `FileList`), `files` — для каждого `name`, `status` (`uploading`, `checking`, `ok`, `error`), `size`, `progress`, `message`; `onRemove`, `accept`, `hint`.

- Ошибку пишет ассистент языком клиента: «Фото обрезано: не видно страницы с подписью. Загрузите разворот целиком».
- Статус `checking` означает автоматическую проверку до отправки в банк — так банк не дозапрашивает документы.
- Зона — это `<label>` со скрытым `input type=file`: работает с клавиатуры и скринридером.
