# ExampleScreen

Пример экрана «Подбор финансирования», собранный только из компонентов системы: навигация, две ProductCard с PaymentLoadMeter и панель ассистента.

Это не компонент бандла, а образец компоновки для команды. Каркас: `sidebar-width` слева, контент, `assistant-width` справа; фон экрана `bg`, панели `surface`, разделители `line`.
