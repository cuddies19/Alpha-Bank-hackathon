# Badge

Статус в одно-два слова на мягком фоне, всегда с иконкой.

**Что передать:** `tone` и текст. Иконка подставляется по тону; `icon={false}` убирает её, своя — `icon="calendar"`.

| Тон | Слова |
| --- | --- |
| `success` | Одобрено, Принят, Подписано |
| `info` | На проверке, Проверяем |
| `warning` | Нужен документ, Скоро платёж |
| `danger` | Отказ, Нужно заменить |
| `accent` | Рекомендуем — сплошная заливка `accent`, единственный «громкий» бейдж |
| `neutral` | Черновик, Загружается |

- Не используйте Badge как кнопку и не ставьте больше двух рядом.
