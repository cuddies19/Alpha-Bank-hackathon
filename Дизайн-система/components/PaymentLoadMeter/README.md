# PaymentLoadMeter

Шкала, которая показывает ежемесячный платёж как долю чистого денежного потока бизнеса и называет зону словом.

**Что передать:** `payment` и `cashFlow` в рублях; пороги `warnAt` и `riskAt` (доли, по умолчанию 0.3 и 0.5 — это параметры-заглушки, их значения нужно согласовать с экспертами банка).

- Зона дублируется словом и иконкой: «Комфортно», «На грани», «Высокая нагрузка».
- Ставьте рядом с каждой суммой, которую клиент выбирает: в ProductCard, в калькуляторе, в ответе ассистента.
- Это предварительная оценка, а не скоринг; не подписывайте её как «одобрят» или «не одобрят».
