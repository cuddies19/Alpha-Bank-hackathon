# Icon

Линейная иконка 24×24 с обводкой 1.75 и цветом `currentColor`.

**Что передать:** `name` из набора (`sparkle`, `document`, `check-circle`…), `size` в px (16, 20 или 24 — токены `icon-sm`, `icon-md`, `icon-lg`), `title`, если иконка несёт смысл без подписи.

- Цвет задаёт родитель через `color`: `ink` для нейтральных, `ink-secondary` для служебных, статусные токены — только вместе со словом.
- `sparkle` — знак ассистента. Только там, где контент создал или заполнил ассистент: аватар, «Заполнено ассистентом», «Рекомендуем», подсказка `Alert tone="assistant"`. Не декор.
- Не смешивайте с иконками других наборов и не заливайте контурные иконки.
