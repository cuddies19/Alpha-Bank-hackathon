# MetricTile

Плитка с одной цифрой бизнеса: подпись, значение, изменение или пояснение.

**Что передать:** `label`, `value` (уже отформатированный: `formatMoney(2340500)`), по желанию `icon`, `delta` (`value`, `direction`, `tone`, `label`) или `hint`.

- На Главной — 3 плитки в ряд на десктопе, в столбик на мобильном.
- Изменение всегда с периодом сравнения: «+12% к сентябрю».
- Тон `delta` — оценка для бизнеса, а не направление: рост платежей — `danger`, рост поступлений — `success`.
