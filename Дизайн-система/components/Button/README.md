# Button

Кнопка действия; `primary` — главное действие экрана, не больше одной на экран.

**Что передать:** текст (глагол: «Оформить заявку», «Загрузить выписку»), `variant`, `size`, по желанию `iconLeft`/`iconRight`, `loading` на время запроса.

| Вариант | Когда |
| --- | --- |
| `primary` | Шаг вперёд по пути клиента: «Оформить заявку», «Отправить», «Подписать» |
| `secondary` | Равноправная альтернатива: «Сравнить продукты» |
| `ghost` | Тихие действия в карточках и панелях: «Позже», «Выбрать» |
| `link` | Переход внутри текста: «Условия продукта» |

- `size="lg"` — главная кнопка на мобильном, во всю ширину (`fullWidth`).
- Во время `loading` текст меняется на процесс: «Отправляем», а не «Загрузка…».
- Не делайте неактивную кнопку единственной подсказкой — объясните рядом, чего не хватает.
