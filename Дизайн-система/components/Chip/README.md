# Chip

Быстрый ответ ассистенту или фильтр — пилюля, которая нажимается одним касанием.

**Что передать:** короткий текст ответа своими словами клиента («1–3 млн ₽», «Кассовый разрыв»), `selected`, `onClick`.

- В чате кладите 2–4 Chip в `footer` сообщения ассистента; клиент всегда может ответить текстом.
- Выбранный Chip инвертируется (`surface-inverse` + `ink-inverse`), а не краснеет: красный занят действиями и ошибками.
- Текст — ответ клиента, а не команда интерфейса: «До 1 млн ₽», а не «Выбрать диапазон 1».
