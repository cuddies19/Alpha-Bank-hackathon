# ChatComposer

Поле ввода сообщения ассистенту с кнопками «Прикрепить» и «Отправить» и дисклеймером под ним.

**Что передать:** `onSend`; `value`/`onChange` для управляемого режима; `onAttach`, чтобы показать скрепку; `placeholder` под контекст экрана.

- Enter отправляет, Shift+Enter — новая строка; поле растёт до 5 строк.
- Дисклеймер «Ассистент может ошибаться. Решение по кредиту принимает банк» не убирайте в продакшене.
- Плейсхолдер подсказывает, что писать: «Опишите задачу своими словами», «Спросите про условия».
