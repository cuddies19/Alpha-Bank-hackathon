# StatusTracker

Вертикальная лента этапов рассмотрения заявки со временем, пояснением и действием.

**Что передать:** `stages` — для каждого `title`, `status` (`done`, `current`, `pending`, `attention`, `failed`), `time`, `description`, `action` (обычно Button `size="sm"`).

- Этап `attention` объясняет, зачем банку документ, и содержит кнопку, а не ссылку «в раздел документов».
- Время — фактическое для прошедших этапов («Сегодня, 10:42») и ожидаемое для будущих, только если банк его гарантирует.
- Каждый статус озвучивается словом для скринридера; цвет — дополнительный сигнал.
