# Card

Белая поверхность с радиусом `radius-lg` на фоне `bg` — базовый блок кабинета.

**Что передать:** содержимое; `padding` (`sm` 16px, `md` 24px, `lg` 32px); `as="button"` или `as="a"` вместе с `interactive` для кликабельной карточки; `tone="accent"` для совета ассистента.

- Карточки отделяются от фона цветом, тень только у интерактивных (`shadow-sm`, при наведении `shadow-md`).
- Одна мысль — одна карточка: заголовок `title-3`, текст `body`, одно действие.
- Не вкладывайте Card в Card; внутри используйте разделители `line`.
