# ChatMessage

Сообщение в диалоге с ассистентом: слева пузырь ассистента с красным знаком, справа тёмный пузырь клиента.

**Что передать:** `role`, текст в `children` (несколько абзацев — `<p>`), `time`, `typing` для индикатора набора, `footer` для Chip, ProductCard или PaymentLoadMeter под пузырём.

- Ассистент пишет `body-lg`, клиент — `body`.
- Цифры и рекомендации ассистент показывает структурными компонентами в `footer`, а не текстом.
- Один вопрос в одном сообщении. Быстрые ответы — Chip в `footer`.
- Ленту сообщений оборачивайте в контейнер с `aria-live="polite"`.
