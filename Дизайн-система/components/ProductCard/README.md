# ProductCard

Карточка кредитного продукта с суммой, параметрами, причинами выбора и действием — главный результат работы ассистента.

**Что передать:** `name`, `purpose` (для какой задачи, языком клиента), `amount`, `amountLabel`, `params` (2–3 пары «Срок», «Ставка», «Платёж»), `reasons` (2–3 факта о бизнесе клиента), `recommended` для одного лучшего варианта, `primaryAction`, `secondaryAction`, в `children` — PaymentLoadMeter.

- Рекомендованная карточка одна; альтернатива — без `recommended`, рядом или ниже.
- Причины — факты из данных клиента («Выплаты маркетплейса приходят раз в две недели»), а не рекламные свойства продукта.
- Цифры ставки и лимита — только из каталога продуктов, никогда из текста модели.
- `preliminary` не отключайте до решения банка.
