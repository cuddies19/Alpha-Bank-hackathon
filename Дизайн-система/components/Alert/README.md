# Alert

Сообщение на экране: системный статус (`info`, `success`, `warning`, `danger`) или подсказка ассистента (`assistant`).

**Что передать:** `tone`, `title` (суть в одной фразе), текст в `children`, по желанию `action` (Button `size="sm"`) и `onClose`.

- `assistant` — белая карточка с красным знаком: так ассистент проактивно предупреждает о разрыве или подсказывает следующий шаг.
- Заголовок — что случилось, текст — что делать: «Не удалось отправить заявку» / «Проверьте соединение и отправьте ещё раз — данные сохранены».
- `danger` объявляется скринридером сразу (`role="alert"`), остальные — вежливо.
