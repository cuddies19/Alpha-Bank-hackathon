# TextField

Поле ввода с подписью сверху, подсказкой или ошибкой снизу и меткой «Заполнено ассистентом».

**Что передать:** `label`, `value`/`onChange` (или `defaultValue`), `hint`, `error`, `suffix` («мес.», «%»), `format="money"` для сумм, `prefilled`, если значение подставил ассистент.

- Подпись всегда видима; плейсхолдер — только пример формата («name@company.ru»).
- `format="money"` сам группирует разряды и показывает «₽»; в `value` придёт строка с неразрывными пробелами — очищайте её от нецифр перед отправкой.
- Ошибка говорит, что не так и как исправить: «У ООО в ИНН 10 цифр — здесь 8», а не «Неверный формат».
- `prefilled` ставьте на каждое поле, взятое из данных банка или диалога, — клиент должен видеть, что проверить.
