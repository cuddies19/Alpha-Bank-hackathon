# Stepper

Горизонтальные шаги заявки: пройденные с галочкой, текущий — красный кружок с номером.

**Что передать:** `steps` (`label` и по желанию `description`: «Заполнено из счёта»), `current` — индекс текущего шага.

- 3–4 шага, не больше. Заявка в MVP: «Параметры», «Данные бизнеса», «Документы».
- На ширине до 600px подписи остаются только у текущего шага.
