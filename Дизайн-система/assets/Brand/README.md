# Знак

- `assistant-mark.svg` — знак ИИ-ассистента: круг `brand` (#ef3124) с белой звездой `sparkle`. Аватар в чате, кнопка вызова ассистента, фавикон демо. Минимальный размер 24px, вокруг — свободное поле не меньше 8px.

Логотипа у продукта нет: название «Кредитный кабинет» набирается шрифтом Golos Text, начертание 700, цвет `ink`. Логотип банка в систему не входит и не перерисовывается.
