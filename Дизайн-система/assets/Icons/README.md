# Иконки

20 линейных иконок на сетке 24×24, обводка 1.75, скруглённые концы. Файлы нарисованы цветом `ink` светлой темы (#121214) — для `<img>` на тёмной теме берите компонент `Icon`: он рисует `currentColor`.

- `sparkle` — знак ассистента, только для контента от ассистента.
- `check-circle`, `clock`, `alert`, `x-circle` — статусы; всегда рядом со словом.
- Остальные — служебные: `document`, `upload`, `paperclip`, `wallet`, `calendar`, `shield`, стрелки и шевроны.

Набор нарисован для этой системы, это не иконки банка.
