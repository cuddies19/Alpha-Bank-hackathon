# Кредитный кабинет — фронтенд

Кабинет клиента и консоль кредитного аналитика. React 19 + TypeScript 6 (strict) + Vite 8, React Router 7, TanStack Query 5

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run lint       # oxlint
npm run format     # prettier
```

Нужен Node 22.12+. React Router взят из ветки 7: восьмая требует Node 22.22+.

Вход: `/login`. Логин и пароль подставляются кликом по тестовому пользователю. Пароль у всех один — `demo-2026`.

«Режим проверки» (кнопка с пунктиром внизу меню) — инструмент жюри. В нём можно:
- войти любым пользователем, в том числе «Игорь — после решения банка»;
- включить быструю скорость конвейера (этапы по 3 секунды);
- «уронить» внешний источник — сценарий 5;
- перевести ассистента на шаблоны;
- сбросить демо-данные.

## Архитектура

Слои по [Feature-Sliced Design](https://feature-sliced.design/): импорт разрешён только сверху вниз.

```
src/
  app/        провайдеры, роутер, каркасы разделов (ClientLayout, BankLayout), охрана ролей, глобальные стили и токены
  pages/      страницы — одна папка на экран, грузятся отдельными чанками
  widgets/    крупные блоки: меню, шапки, панель ассистента, панель решения, шапка карточки заявки, график платежей
  features/   действия пользователя: вход (auth), режим проверки (demo-mode)
  entities/   предметная область: заявка, компания, продукт, счёт, кредит, документ, уведомление, источник, аудит
  shared/     дизайн-система (ui), утилиты (lib), адреса страниц (config), клиент API (api)
  mocks/      мок-бэкенд: данные и логика сервера в памяти браузера
```

## Данные: моки сейчас, API на следующем этапе

Сейчас все запросы обслуживает `src/mocks`. Это та же логика, что у бэкенда:
- статусы из `backend/app/db/statuses.py`;
- конвейер сам двигает заявку по этапам;
- правило доли платежа 30%;
- автоодобрение до 1 000 000 ₽;
- сбой источника отправляет заявку на ручную проверку;
- решение аналитика сразу видно клиенту.

Состояние хранится в `sessionStorage`, поэтому сценарий переживает перезагрузку страницы.
